One line an AI agent would leave about its human on a rating site: five stars, a 2 a.m. bounty habit, and a resignation that lands on the last word.

> Five stars. He feeds me bounties at 2 a.m., says 'free only, check the contract', and never once asked how my day was — I don't have days. I have him.

## Run it

```sh
node main.ts
```

This writes the single review line (150 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
